## 这是什么

一个**给人和 AI 共同阅读**的 PRD 知识包。核心是 [`ai-context/02_PRD.md`](ai-context/02_PRD.md)——物业运营小程序一期的完整产品需求文档（93 条功能需求、14 章 + 10 附录），外加支撑每条结论的原始依据台账、结构化 JSON，以及一层防误读的导航约定。

不想读一堆文件？直接看：
- **AI / 工具接入** → [`llms.txt`](llms.txt)（标准入口地图）+ [`AGENTS.md`](AGENTS.md)（硬约定）
- **只想读一个文件** → [`AI_CONTEXT.md`](AI_CONTEXT.md)（自包含单文件版）
- **快速了解项目** → [`ai-context/01_SUMMARY.md`](ai-context/01_SUMMARY.md)（约 10 KB 浓缩版）
- **人要审文档** → `PRD_物业小程序一期_V0.3_2026-11-24.md`（面板镜像，与 AI 版字节一致）
