## 2. 术语消歧（高危）

| 词 | 唯一含义 | 不要混淆成 |
|---|---|---|
| **打卡** | 到点位签到（清单 1.4 旧义） | 问题上报（`AC-10` 已关闭） |
| **随手拍** | 问题上报现场取证（§1.1 义） | 巡查点位打卡 |
| **日常巡查** | **内容类型** `DAILY_ORDER`（公区异常 + 可疑人员） | 早/晚两班的频次级别（`AC-11`） |
| **日/周/月频次** | 频次级别 `DAILY`/`WEEKLY`/`MONTHLY` | 巡查类型 |
| **商户** | 园区 **46 家企业**（`L-C2`） | 访客、外部人员、商铺顾客 |
| **L1 / L2** | 身份等级：L1=微信 openid，L2=企微 `qy_userid` | 角色 R1~R8、问题等级 L1~L4 |
| **L1~L4（上报）** | `report_level` 4 档问题紧急度 | `auth_level` 的 L1/L2 |
| **红线 / 一般 / 观察** | §4.3 的 `rectify_level` 三档（合规定性，R2 复核定） | `report_level` 四档（现场紧急度，R1 判） |
| **国标值 / 培训值** | 国标判「是否合法」；培训值判「是否达公司标准」 | 二者不可互相替代、不可取其一 |
| **逻辑点位** | 一期系统内的虚拟点位，`check_points` 主数据 | 二期实体 NFC 标签 / 二维码码牌 |
| **外协维保** | R8 外协单位的作业人员 | R3 工程主管邓令升（物业方管理岗） |
| **FACILITY** | 人工目视打勾 + 照片巡检大型设施 | 消防主机联网 / 电梯 IoT（一期不做） |

## 3. 枚举值速查

| 字段 | 取值 |
|---|---|
| `patrol_type` | `DAILY_ORDER` / `FIRE` |
| `frequency` | `DAILY` / `WEEKLY` / `MONTHLY`（称「日/周/月频次」） |
| `fire_domain` | 器材 / 商户内部 / 整改复查 / 大型设施 `FACILITY` |
| `auth_level` | `L1`（微信）/ `L2`（企微） |
| `report_level` | `L1` 提示 / `L2` 一般 / `L3` 严重 / `L4` 紧急 |
| `rectify_level` | 红线 / 一般 / 观察 |
| `checkin_method` | 一期 `PHOTO_WATERMARK`；二期预留 `NFC` / `QRCODE` / `COMBINED` |
| `check_item.result` | 三态（合格 / 不合格 / 不适用）+ 照片 |
| `target_type` | 公区 / 商户 / 设施 |
